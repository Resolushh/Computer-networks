# Компьютерные сети

Репозиторий содержит учебные задания, схемы сетей и конспекты. Каждая учебная ветка посвящена отдельной работе и имеет собственный README с описанием материалов и результатов.

## Навигация по веткам

| Ветка | Тема |
|---|---|
| `lesson_2` | Сетевые неисправности и уровни OSI |
| `lesson_3` | Захват и разбор трафика в Wireshark |
| `lesson_4` | MAC-адреса, коммутация и поиск неисправностей |
| `lesson_5` | Расчёт маски подсети и построение сети |
| `lesson_6` | Проверка ping и прохождение ICMP |
| `lesson_7` | Правила брандмауэра для Packet Tracer |
| `lesson_8` | Деление IPv4-сетей на подсети |
| `lesson_9` | Топологии с маршрутизаторами |
| `lesson_11` | Работа по теме RIP и проверка связи |
| `lesson_12` | Конспект по DHCP |
| `lesson_13` | NAT и доступ к локальному веб-серверу |
| `practise_work` | Самостоятельная работа по основам сетей |

## Просмотр работы

Выберите ветку в интерфейсе GitHub или переключитесь на неё локально, например:

```bash
git switch lesson_13
```

Откройте README и приложенные изображения или PDF. Скриншоты Packet Tracer показывают сохранённые результаты; редактируемые проекты `.pkt` в текущих учебных ветках не приложены.
