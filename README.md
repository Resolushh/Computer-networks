# Занятие 12. Протокол DHCP

В ветке находится конспект об автоматическом назначении сетевых параметров с помощью DHCP.

Документ описывает назначение DHCP и его связь с RARP и BOOTP, режимы распределения адресов, пул и срок аренды. Рассматривается роль DHCP Relay при обслуживании клиентов из другой подсети.

## Что происходит при получении адреса

Клиент ищет сервер сообщением Discover, получает предложение Offer, запрашивает выбранные параметры сообщением Request и получает подтверждение ACK. После этого клиент применяет адрес и остальные настройки. Далее рассматриваются продление и освобождение аренды.

Отдельная часть посвящена связи DHCP с DNS, удалённым управлением и фильтрацией трафика, а также выбору постоянных адресов для инфраструктурных устройств.
