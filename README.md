# Занятие 7. Правила брандмауэра для Cisco Packet Tracer

В работе показаны правила брандмауэра Windows для входящих и исходящих соединений Cisco Packet Tracer.

Оба правила включены, распространяются на все профили и используют действие блокировки. В показанных столбцах ограничения по адресам, протоколам и портам обозначены как «Любой». Правила применяются к программе Packet Tracer.
