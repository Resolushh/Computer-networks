# Занятие 8. Расчёт IPv4-подсетей

В работе решены две задачи деления сетей `/24` на равные подсети.

## Задание 1

Для сети `192.168.0.0/24` требуется не менее пяти подсетей по 25 хостов. Выбрана маска `/27` (`255.255.255.224`): она даёт восемь подсетей, по 32 адреса и 30 доступных адресов устройств в каждой.

## Задание 2

Для сети `192.168.50.0/24` требуется шесть подсетей. При равном размере выбрана та же маска `/27`: доступны восемь подсетей, из которых можно использовать шесть. Шаг адресов сетей равен 32.

В документе перечислены все восемь подсетей, диапазоны адресов устройств и broadcast-адреса. Например, первая подсеть — `192.168.50.0/27`, хосты — `192.168.50.1–192.168.50.30`, broadcast — `192.168.50.31`.
