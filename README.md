# Занятие 2. Сетевые неисправности и уровни OSI

В работе сетевые неисправности сопоставлены с уровнями модели OSI. Для каждого примера приведено объяснение, какая функция сети затронута.

## Разобранные примеры

| Неисправность | Уровень OSI | Объяснение |
|---|---|---|
| Не принимается сигнал Wi-Fi | 1. Физический | Передача радиосигнала между устройством и точкой доступа |
| Ошибка CRC Ethernet-кадра | 2. Канальный | Проверка целостности кадра |
| Нет маршрута до сервера | 3. Сетевой | Выбор маршрута до IP-адреса назначения |
| Закрыт TCP-порт | 4. Транспортный | Доступность порта и установление TCP-соединения |
| Ошибка DNS | 7. Прикладной | Преобразование доменного имени в IP-адрес |
