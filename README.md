# Самостоятельная работа по компьютерным сетям

В ветке собраны ответы на теоретические вопросы и расчётные задания по основам компьютерных сетей.

## Содержание

- Основные понятия: топологии, LAN и WAN, уровни OSI и TCP/IP, TCP и UDP.
- IPv4: двоичная запись, частные адреса, маски, количество адресов, broadcast и шлюз.
- MAC-адреса: формат, OUI, адрес устройства, широковещание и таблица коммутации.
- Маршрутизация: таблица маршрутов, маршрут по умолчанию, наиболее длинный префикс, статическая и динамическая маршрутизация.
- Практическая часть: расчёт подсетей и вопрос об инкапсуляции HTTP-запроса.

## Результат

Для сети `172.16.0.0/16` рассчитаны подсети `/23`: 128 подсетей по 510 адресов устройств. Первая подсеть — `172.16.0.0/23`, хосты — `172.16.0.1–172.16.1.254`, broadcast — `172.16.1.255`.

В документе объединены теоретические ответы, примеры выбора маршрута и расчёт адресного пространства для подсетей.
