# Занятие 9. Топологии сети с маршрутизаторами

В ветке представлены две схемы, собранные в Cisco Packet Tracer.

Первая схема объединяет четыре компьютера, пять маршрутизаторов 1841 и три концентратора. Компьютеры подключены к разным участкам сети, а маршрутизаторы связаны через общие сегменты с концентраторами.

Во второй схеме три маршрутизатора R1, R2 и R3 соединены треугольником. К ним через пять коммутаторов подключены пять компьютеров. Голубые линии показывают консольные подключения для настройки устройств.
