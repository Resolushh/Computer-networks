# Занятие 17. HTTP и работа с запросами

В работе разобраны основные понятия HTTP и структура запроса и ответа. В примерах показаны операции чтения, создания, удаления и изменения товара.

## Материалы

- [Разбор HTTP и примеры запросов](HTTP.md)

## Итог

HTTP-запрос состоит из метода, пути, версии протокола, заголовков и, когда это нужно, тела. Ответ сообщает результат операции с помощью статус-кода, заголовков и данных. Для товаров составлены запросы GET, POST, DELETE и PATCH.
