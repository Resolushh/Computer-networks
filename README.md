# 🌐 Компьютерные сети

> Репозиторий, посвящённый изучению компьютерных сетей, принципов их построения и взаимодействия сетевых устройств.

**Добро пожаловать!** 👋

Этот проект создан для того, чтобы собрать и систематизировать учебные материалы, практические работы и задания по компьютерным сетям. Здесь рассматриваются основные сетевые технологии, протоколы, модели взаимодействия устройств и принципы передачи данных.
