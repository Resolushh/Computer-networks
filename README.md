# Занятие 7. Правила брандмауэра для Cisco Packet Tracer

В работе показаны правила брандмауэра Windows для входящих и исходящих соединений Cisco Packet Tracer.

Оба правила включены, распространяются на все профили и используют действие блокировки. В показанных столбцах ограничения по адресам, протоколам и портам обозначены как «Любой». Правила относятся к программе Packet Tracer; точный путь к исполняемому файлу на скриншотах обрезан.

## Материалы

- [input_connection.png](input_connection.png) — правило для входящих соединений.
- [output_connection.png](output_connection.png) — правило для исходящих соединений.

## Что показывает работа

Скриншоты фиксируют параметры правил, ограничивающих сетевые соединения приложения. Результатов проверки блокировки и экспортированного набора правил в ветке нет. Эти правила Windows следует отличать от настроек виртуальных устройств внутри Packet Tracer.
