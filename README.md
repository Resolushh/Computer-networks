## Краткая выжимка

Транспортный уровень отвечает за передачу данных между приложениями на разных компьютерах.
Для этого используются протоколы TCP и UDP, а нужное приложение определяется по номеру порта.
TCP устанавливает соединение, следит за порядком данных и повторно отправляет потерянные части.
UDP передаёт сообщения без установления соединения и не гарантирует их доставку.
Поэтому у UDP меньше накладных расходов, а TCP подходит для задач, где важна надёжность передачи.

TCP-соединение устанавливается в три шага: SYN, SYN + ACK и ACK.
Для эффективной передачи TCP использует скользящее окно, позволяющее отправлять несколько частей данных без ожидания каждого подтверждения.
Управление потоком защищает получателя от переполнения буфера, а управление перегрузкой помогает снизить нагрузку на сеть.
TCP применяется, например, в FTP и SMTP, а UDP - в DHCP и TFTP.
DNS может использовать оба протокола и работает через порт 53.
