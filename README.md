# Занятие 5. Подсети и построение сети

В работе рассматривается выбор маски для сети, где требуется не менее 20 подсетей и не менее 10 узлов в каждой, а также построение топологии в Cisco Packet Tracer.

В расчёте для количества подсетей выделено 5 бит: `2^5 = 32`. Для узлов выделено 4 бита: `2^4 - 2 = 14`. Получен префикс `/28` и маска `255.255.255.240`. Одновременное выделение этих битов предполагает исходный префикс не длиннее `/23`; исходная сеть в текстовом ответе не указана.
